# Muse USB設定（Web Serial）

USBで接続したMuseの現在値をブラウザに表示し、消灯時間・明るさ・音量・
スピーカーON/OFF・マイクゲインを変更する。既存の`>status`と設定コマンドを
使うため、対応するMuseファームウェアの書き換えは不要。
BLE設定画面`ble_setup.html`とは別の、USB接続用の画面。

## 起動

リポジトリの`esp32`ディレクトリで次を実行する。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory tools/muse
```

Chromeで[USB設定画面](http://localhost:8765/serial_setup.html)を開き、
「USBで接続」から実機のポートを選択する。Web SerialはlocalhostまたはHTTPSを
必要とする。詳細は[Chrome公式資料](https://developer.chrome.com/docs/capabilities/serial)を参照。

1. 接続後に実機の現在値が表示される。接続時に設定の書き込みは行わない。
2. 値を変更し「変更を保存」を押す。実機の応答と読み戻しの一致を確認する。
3. 「切断する」でポートを解放する。他のシリアルモニターとは同時に接続しない。

自動消灯の`0`は消灯しない設定。`1〜3600`は消灯までの秒数。
明るさは10〜100%、音量は0〜100%、マイクゲインは0〜36 dB。
設定は実機に保存され、再起動後も保持される。
「画面を起こす」は復帰コマンドを送るだけで、未保存の編集を取り消さない。
録音、通話、TTS、Wi-Fi設定の変更や初期化、SDKトークン入力、ファームウェア更新は行わない。

接続操作で実機が再起動する場合がある。設定の応答がない場合は、他の
シリアルモニターを閉じ、USBを接続し直す。接続中にケーブルを抜いた場合は
再接続する。応答や読み戻しを確認できなかった保存は成功扱いにしない。

外部ライブラリ、CDN、通信API、ブラウザストレージは使わない。
USBで読み取る状態にはWi-Fi名や接続情報が含まれるが、画面の操作履歴には
生のシリアル出力や会話本文を記録しない。

## テスト

Node.js 22以降で、実機を使わない通信テストを実行できる。

```sh
node --test tools/muse/serial_settings.test.mjs
```

分割されたUTF-8/JSON、応答の順序、読み戻し不一致、範囲外入力、通信切断、
書き込み停滞・タイムアウトとロック解放を確認する。
